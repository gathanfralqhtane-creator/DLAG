# 🛡️ DLAG-Network v2.1 (Official)

**DLAG** هي أداة متطورة لاختراق وتتبع الأجهزة عن بعد باستخدام ثغرات النظام الحديثة 2026. تتيح لك الأداة الوصول الكامل للأجهزة المستهدفة عبر بروتوكولات مشفرة.

## 🚀 كيفية التثبيت (Installation)
افتح تطبيق **Termux** وقم بنسخ ولصق الأوامر التالية بالترتيب:

```bash
pkg update && pkg upgrade -y
pkg install git python -y
pip install requests
git clone [https://github.com/gathanfralqhtane-creator/DLAG](https://github.com/gathanfralqhtane-creator/DLAG)
cd DLAG
python dlag.py
